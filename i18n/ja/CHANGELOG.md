## [0.1.5] - 2026-11-23

### 追加 (Added)
- **アプリ内セルフアップデート（ダウンロード・検証・自動再起動）**：
  - 「アップデートを確認」ダイアログ内にワンクリックの **今すぐアップデート** を追加し、ブラウザを開いて手動でダウンロード・ドラッグインストールする手間を解消しました。
  - GitHub Release の `.zip` をリアルタイム進捗付きでストリーミング取得し、`CryptoKit` による `SHA256SUMS.txt` 検証と `CFBundleIdentifier` の確認を行ったうえで、`/usr/bin/ditto` で展開して `ProZip.app` をアトミックに置換（失敗時の自動ロールバックおよび必要に応じた管理者認証プロンプトに対応）し、自動で再起動します。

### 修正・変更 (Fixed & Changed)
- **モノクロテンプレートのメニューバーアイコンとシェルフの位置調整**：
  - カラーのメニューバーアイコンを、ブランド文字 **P** と不透明度 33% のシャドウのみで構成された解像度非依存の macOS テンプレートアイコン（`isTemplate = true`）に刷新し、ライトモード／ダークモードへ自動追従するようにしました。
  - メニューバーシェルフパネルの上部インセットを詰め、メニューバー下端に密着させることで余分な隙間を解消し、設定画面のプレビュー表示とも整合させました。
- **リアルタイム展開進捗表示**：分割 RAR を含むすべての対応アーカイブ形式で、展開進捗をリアルタイムにストリーミング表示するよう改善しました。

## [0.1.4] - 2026-11-21

### 追加 (Added)
- **Dock 表示／非表示の設定**：設定 → 一般 → 起動 に **Dock に表示** トグルを追加し、アクティブなウインドウのフォーカスを維持したまま再起動なしで `NSApplication.ActivationPolicy`（`.regular` / `.accessory`）を即時切り替えられるようにしました。あわせてメニューバー Box の右クリックメニューに **設定…** を追加し、簡体字中国語・繁体字中国語・英語のローカライズに対応しました。
- **タスクキューの細やかな整理機能とリサイズ可能な独立作成ウインドウ**：
  - `ArchiveProgressWindowView` にタスク単位の消去ボタン、失敗タスクを含む **完了項目を消去**、および **すべて消去** アクションを追加しました。
  - `ArchiveCreationDialogView` をサイズ記憶付きの独立したリサイズ可能ウインドウとしてホストするよう変更し、概要欄のクリーンアップ／互換性に関する行を直接クリックで切り替えられるトグルにしました。

### 変更 (Changed)
- **アイドル時のメモリ回収とバックグラウンド CPU ウェイクアップのゼロ化**：
  - `ProZipLandingView` の見出しローテーションを `isWindowActive` に連動させ、バックグラウンド化・非フォーカス・最小化時にはアニメーションループを即座に一時停止してアイドル時の CPU ウェイクアップをゼロにしました。
  - ようこそウインドウ、設定ウインドウ（記憶サイズは保持）、メニューバーシェルフパネル、タスク進捗パネル、およびアラートウインドウを閉じた際に `NSHostingView` 階層とバッキングバッファを解放するようにし、アクティブなアーカイブセッションが既に存在する場合はようこそウインドウを事前生成しないようにしました。
  - `ProZipResourceImageLoader` をコスト上限付きの `NSCache`（設定ウインドウを閉じた際にパージ）へ移行し、メニューバーのステータス項目アイコンを `512×512` の元ビットマップ保持ではなく `18×18` でラスタライズするようにしました。
- **リアルタイムのストリーミング圧縮進捗とエンジンの事前ウォームアップ**：`NativeZipEngine` に 512 KiB チャンク単位の進捗通知を追加し、`SevenZipEngine` に `-bsp1` によるライブ進捗ストリーミング（設定された `-mmt` スレッド数および `-xr!.DS_Store/__MACOSX/._*` 除外ルールを転送）を導入しました。さらに `@MainActor` 外でのバックグラウンドエンジン事前ウォームアップを追加しました。

## [0.1.3] - 2026-11-14

### 追加 (Added)
- **Finder のスペースキーによる ProZip Mini トグル起動**：macOS のアクセシビリティおよびオートメーション（AppleEvents）権限を利用した `FinderSpacebarMonitor` を追加しました。Finder で対応アーカイブを選択してスペースキーを押すと直接 ProZip Mini が開き、Mini 内で再度スペースキーを押すとウインドウを閉じて Finder にフォーカスを戻します（設定 → ProZip Mini にて権限オンボーディングと対象形式の範囲を設定可能）。
- **パスワードブックのキーチェーン認証復元とリセット用フォールバック**：オープンソース版／アドホック再署名バイナリによって従来のキーチェーン ACL が無効化された場合でも既存の暗号化ボールトを保持し、システムキーチェーン UI で一度だけ認証して保存済みエントリを復号し現在のアプリ署名に紐づく新しい鍵へローテーションする **パスワードブックを認証して復元**（以降はサイレント起動が可能）と、2段階確認付きの **パスワードブックをリセットして再構築** フォールバックを設定 → パスワードブックおよび保護ダイアログに追加しました。

### 変更 (Changed)
- **ProZip Mini ヘッダでのアーカイブサイズ表示**：Mini ウインドウのサブタイトルに、項目数とフォーマット済みアーカイブファイルサイズの両方を表示するよう更新しました。
- **Touch ID クイック解錠のアドホックビルド対応**：Apple Team ID を持たないビルドでは Touch ID クイック解錠トグルを適切に無効化しつつ、将来の署名付きビルド向けに Data Protection Keychain の完全な実装を維持しました。
- **README にインタラクティブデモ GIF を追加**：[README.md](README.md) に UI モードやワークフローを紹介する `Resources/ProZip-Demo.gif` を追加しました。

### 修正 (Fixed)
- アーカイブ作成オプションシート（`ArchiveCreationDialogView`）のヘッダ、フッタ、または背景領域をドラッグしてもホストウインドウが移動しない問題を修正しました（`WindowDragArea.resolveRootWindow` による親ウインドウチェーン解決とマウスドラッグ追跡）。
- Finder のスペースキープレビューから起動した後に、スペースキーで ProZip Mini ウインドウを閉じられない問題を修正しました。

## [0.1.2] - 2026-11-12

### 追加 (Added)
- **GitHub Releases 自動アップデートサービスと UI 統合**：GitHub Releases API への問い合わせ、セマンティックバージョン比較、リリースノート要約の表示、`.dmg` / `.zip` 直接ダウンロードリンクの起動を行う `AppUpdateService` を導入し、「アップデートを確認」ダイアログ、設定 → このアプリについて、および起動時のサイレント確認（24時間スロットリング）に統合しました。
- **ネイティブ macOS 26+ Liquid Glass デザインシステム**：ネイティブの `.glassEffect` と `GlassEffectContainer` を活用した統一カプセル・円形・連続曲率コーナーの Liquid Glass モディファイアを構築し、macOS 14–15 向けには滑らかなフロストマテリアルのフォールバックを用意しました。

### 変更 (Changed)
- **Mini ウインドウの光学屈折とインタラクションの洗練**：
  - Mini ウインドウの Liquid Glass エッジ屈折、`20pt` の連続コーナー半径、ライト／ダーク背景での透過度を調整し、四隅のフレームアーティファクトを解消しました。
  - 左下の円形コントロール（閉じる、スカイブルーのハローリング付きピン留め、展開）および右下の `プレビュー + すべて展開` カプセルをネイティブのインタラクティブ Liquid Glass に刷新し、セグメントごとの滑らかなホバー着色と押下時のレンズ応答を実現しました。
  - Mini の縦スクロールバースロットを透明化し、下部の段階的フェードマスクを改善しました。
- **Workspace およびようこそウインドウの Liquid Glass アップグレード**：
  - 右上の表示切り替えカプセル、削除／保存／検索の円形ボタン（アクティブ時のクリムゾン色削除ガラスボタンと展開式検索バーを含む）、パンくずナビゲーションピル、左下のアクションバーをネイティブ Liquid Glass にアップグレードしました。
  - Workspace モード下部の静的な白いベールと不要な縦区切り線を削除し、スクロールするファイル行がフローティング Liquid Glass カプセル越しに直接屈折して見えるようにしました。
  - 主要 Flow CTA の発光ガラスリムと重なり合うピークカードインジケータを洗練し、ホバー時に補助アクションの `展開` が滑らかに広がるようにしました。
  - ようこそウインドウの `アーカイブを開く`、`アーカイブを作成`、`設定` コントロールをネイティブ Liquid Glass に統一しました。

### 修正 (Fixed)
- Workspace 下部アクションカプセル内のキーボードショートカットバッジ（`⏎` / `Space`）がホバー時に白地に白文字となり視認できなくなる問題を修正しました。

## [0.1.0] - 2026-11-12

### 追加 (Added)
- **初回オープンソースリリース（GPL-3.0）**：
  - `NativeZipEngine`（ゼロコピーの純粋 Swift ZIP リーダー）、7-Zip（マルチスレッド LZMA2）、システム `libarchive`、および `hdiutil` ディスクイメージマウントを組み合わせた4層アーカイブエンジンアーキテクチャ。
  - 大規模アーカイブでも瞬時に閲覧・検索できる高速階層型 SQLite エントリインデックス（`EntryIndex`）。
  - `1040×740` のマルチビュー Workspace（アイコン、リスト、カラム）と `560×422` のコンパクトな Mini ブラウザをシームレスに切り替えるデュアルモードワークフロー（`⌥⌘M`）。
  - コンテキスト認識型 Flow レコメンドエンジン（アプリバンドルのインストール、フォントのインストール、安全な許可リストに基づく直接起動、ワンクリック展開）。
  - 複数ソースからのドラッグ＆ドロップ一時保管、フォルダ／アーカイブのインライン閲覧、一括圧縮・展開に対応する常駐メニューバーシェルフ。
  - macOS キーチェーン、Touch ID 解錠、自動パスワード照合を備えたローカル AES-GCM 暗号化パスワードブック。
  - Finder コンテキストメニュー拡張機能（`ProZipFinderSync`）およびクイックルックプレビュー拡張機能（`ProZipQuickLook`）を同梱。
