> [!IMPORTANT]
> **Позиционирование и цель проекта**:
> ProZip — независимый полностью открытый проект, созданный для изучения, исследования и практического освоения современной десктопной архитектуры macOS, гибридного проектирования взаимодействия на SwiftUI + AppKit, потоковых конвейеров обработки архивов на базе нескольких движков и принципов «чистой комнаты» (Clean-Room Engineering).
>
> Данное программное обеспечение предназначено исключительно для технического обмена опытом и образовательных целей и не ставит целью конкурировать с какими-либо коммерческими архиваторами на рынке. Каждая строка кода написана самостоятельно с нуля без использования декомпилированного коммерческого кода или неавторизованных ресурсов и распространяется под лицензией [GNU General Public License v3.0](../../LICENSE). Мы тепло приветствуем разработчиков под macOS и участников open-source-сообщества для совместного изучения, обсуждения и развития проекта.

## Почему ProZip

| Ключевая возможность | Описание |
|---|---|
| **Нативная скорость и эстетика** | Написан на чистом Swift и SwiftUI с глубоким соблюдением визуальной иерархии macOS, оптикой Liquid Glass и мгновенным тактильным откликом. |
| **Синергия четырёх движков** | Объединяет `NativeZipEngine` (прямое чтение без копирования), 7-Zip (многопоточный LZMA2), системную `libarchive` и монтирование образов дисков через `hdiutil`. |
| **Мгновенный двухтабличный индекс SQLite** | При открытии архива сразу создаёт локальную иерархическую БД индекса — раскрытие, фильтрация и выборочная распаковка десятков тысяч элементов занимают миллисекунды. |
| **Гибкое двухрежимное рабочее пространство** | Бесшовное переключение (`⌥⌘M`) между полнофункциональным многоколоночным окном Workspace (`1040×740`) и компактным полупрозрачным браузером Mini (`560×422`). |
| **Умный контекстно-зависимый Flow** | Автоматически анализирует содержимое архива (приложения, шрифты, документы и др.) и предлагает уместные действия: **Установить в Программы**, **Установить шрифт** или прямое открытие. |
| **Полка временного хранения в строке меню (ProZip Box)** | Всегда доступная зона перетаскивания в строке меню для сбора файлов из разных папок, встроенного просмотра каталогов и пакетного сжатия в один клик. |
| **Защищённая книга паролей и Touch ID** | Локальное хранилище паролей с шифрованием AES-GCM под защитой Связки ключей macOS (`Keychain`) и Touch ID с автоматическим перебором сохранённых паролей при открытии архивов. |
| **Глубокие системные расширения** | Включает расширение контекстного меню Finder (`FinderSync`) и плагин мгновенного Быстрого просмотра (`Quick Look`) по нажатию клавиши Пробел. |

## Матрица поддерживаемых форматов

| Категория | Поддерживаемые форматы и возможности |
|---|---|
| **Распаковка и просмотр** | ZIP, 7Z, RAR (v4 / v5 / многотомные), TAR, GZ, TGZ, BZ2, TBZ2, XZ, TXZ, ZST, TZST, CPIO, CAB, ISO, DMG и другие |
| **Создание архивов** | ZIP (настраиваемый уровень сжатия Deflate, шифрование AES-256, разбивка на тома), 7Z (высокая степень сжатия LZMA2, шифрование заголовков, разбивка на тома), TAR |
| **Редактирование на месте и сохранение** | Прямое добавление, удаление и переименование элементов внутри существующих однотомных архивов с атомарными транзакциями фиксации и автоматическим откатом при сбое |

## Системные требования

- **Операционная система**: macOS 14.0 (Sonoma) или новее
- **Архитектура**: Нативная поддержка Apple Silicon (серия M) и совместимость с Intel (`x86_64`)
- **Конфиденциальность и среда**: 100% локальная автономная работа — по умолчанию полностью отсутствуют сетевое отслеживание, телеметрия и удалённая аналитика

## Быстрый старт

### 1. Скачайте готовую сборку
Перейдите на страницу [Latest Release](https://github.com/scoltzero/prozip/releases/latest) и скачайте `ProZip-v0.1.5-macos.dmg` или `ProZip-v0.1.5-macos.zip` (список изменений см. в [CHANGELOG.md](CHANGELOG.md)).

### 2. Установите и запустите
1. Откройте образ диска `.dmg` и перетащите `ProZip.app` в папку `Applications` («Программы»).
2. Дважды нажмите на ProZip для запуска. Если macOS выведет предупреждение о неизвестном разработчике, откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **Открыть в любом случае**.
3. Следуйте мастеру первоначальной настройки, чтобы при необходимости включить расширение Finder и плагин Быстрого просмотра (Quick Look).

## Архитектура

ProZip построен на чистой многоуровневой архитектуре, разделяющей представление UI, состояние сессии, индексацию записей и низкоуровневые архивные движки:

```text
┌─────────────────────────────────────────────────────────────┐
│              ProZip App & Extensions Layer                  │
│   (WorkspaceWindowView / MiniWindowView / MenuBarShelf)     │
│   (ProZipFinderSync Extension / ProZipQuickLook Plugin)     │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│                    ProZipUI & ViewModels                    │
│   - AppViewModel (оркестрация сессий и решения Flow)        │
│   - ProZipTheme (нативный стиль, иерархия цветов, анимации) │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│                    ProZipCore Engine Layer                  │
│   - ArchiveBrowsingSession (цикл сессии и стейджинг)        │
│   - EntryIndex (быстрый SQLite-индекс каталогов и записей)  │
│   - PasswordBook (сейф AES-GCM + Keychain + Touch ID)       │
│   - ManagedTemporaryArtifactRegistry (очистка врем. файлов) │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│                   Archive Engine Broker                     │
│   ├─ NativeZipEngine   : чистый Swift, прямое чтение/запись │
│   ├─ SevenZipEngine    : 7-Zip LZMA2 / AES / мультиформаты  │
│   ├─ LibarchiveEngine  : потоковый слой libarchive macOS    │
│   └─ DiskImageEngine   : монтирование образов через hdiutil │
└─────────────────────────────────────────────────────────────┘
```

## Сборка из исходного кода

Проект управляется через Swift Package Manager и включает автоматизированные скрипты упаковки:

### Предварительные требования
- macOS 14.0+ с установленным Xcode 15+ или инструментами командной строки Xcode (Command Line Tools)
- Утилита `7zz`, установленная через Homebrew (используется для включения встроенного подмножества движка 7-Zip):
  ```bash
  brew install sevenzip
  ```

### Шаги сборки
1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/scoltzero/prozip.git
   cd prozip
   ```

2. **Скомпилируйте основные модули Swift**:
   ```bash
   swift build -c release
   ```

3. **Соберите полный пакет приложения `.app` для macOS** (включая расширение Finder и плагин Быстрого просмотра):
   ```bash
   bash scripts/build_app.sh release
   ```
   После завершения готовый бандл приложения будет находиться в `build/ProZip.app`.

## Заявление о независимой разработке и открытом коде

<details>
<summary><strong>Нажмите, чтобы развернуть философию дизайна и границы «чистой комнаты»</strong></summary>

1. **Исследовательская и учебная цель**:
   ProZip задумывался как исследование передовых практик проектирования современных графических интерфейсов для macOS. В ходе разработки мы изучали паттерны взаимодействия, ритмику анимаций, маршрутизацию между движками и потоковые конвейеры ведущих архивных утилит индустрии, после чего самостоятельно спроектировали и реализовали всё с нуля на чистом Swift и SwiftUI.

2. **Инженерия «чистой комнаты» (Clean-Room)**:
   Этот репозиторий не содержит ни единой строки декомпилированного исходного кода, защищённых медиаресурсов или закрытых сертификатов какого-либо проприетарного ПО. Вся бизнес-логика, структуры данных и представления интерфейса написаны с нуля в соответствии с принципами Clean-Room Engineering.

3. **Открытый обмен опытом и некоммерческий характер**:
   Проект опубликован с открытым исходным кодом для содействия обмену опытом между разработчиками, интересующимися десктопными приложениями для macOS, потоковой работой с файловой системой и нативным взаимодействием C/Swift. Мы глубоко уважаем интеллектуальную собственность и мастерство авторов всех коммерческих продуктов и не ставим целью заменить какое-либо коммерческое ПО.
