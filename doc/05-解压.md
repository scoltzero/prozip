# 05 · 解压

## 1. 入口

| 入口 | 目标 | 备注 |
|---|---|---|
| `全部解压 ⏎` | 默认同目录，新建与包同名的文件夹（单层内容时直接用包名目录） | 免费 |
| `解压所选项目…` | 弹目录选择器 | 需索引完成 |
| `压缩包 → 解压所选项目…` | 同上 | 菜单等价入口 |
| Finder 右键 `快速解压到当前目录` | 当前目录 | 不建窗口 |
| Finder 右键 `快速解压到指定目录…` | 用户选择 | 不建窗口 |
| 批量：选中多个包 → `Extract N Files Here/To…` | 每个包各自解压 | 有批量汇总 |
| 拖出条目到 Finder | 落到目标 | file promise |
| 双击（开启"双击时快速解压"） | 同目录 | 跳过浏览 |
| Box → 解压 | Box 临时目录，之后可"保存到…" | |

## 2. 目标目录规则

1. 默认目标 = 压缩包所在目录 + 去扩展名的同名文件夹。
2. 包内只有一层同名目录时，避免 `foo/foo/...` 双层嵌套。
3. 目标目录不存在 → 创建；父路径不是目录 → 报错。
4. 目标是符号链接目录 → **拒绝**（"解压目标包含符号链接目录"），防穿越。
5. 目标不可写 → "Cannot write to this location / 请选择其他文件夹存放解压结果。来源文件不会被修改。"
6. 暂存要求：解压先写私有暂存目录，成功后再发布到目标；暂存目录必须本地、必须为空。

## 3. 冲突策略

| 冲突 | 行为 |
|---|---|
| 同名文件已存在 | 询问：替换 / 保留两者 / 跳过；可"全部应用" |
| 同名但类型不同（文件 vs 目录） | 报"文件与目录结构冲突" |
| 大小写不敏感卷上的同名 | 视为冲突（`volumeSupportsCaseSensitiveNames` 探测） |
| 解压中发现新同名 | "目标位置出现了新的同名项目，请重新拖动并确认替换" |

## 4. 内容过滤（默认开启）

两项独立开关：

1. **自动排除系统辅助文件**：`__MACOSX`、AppleDouble `._*`、`.DS_Store`、`Thumbs.db`、`desktop.ini`、卷索引。
   - **不过滤** `.gitignore`、`.env` 等配置点文件。
   - 显式选中的辅助文件/文件夹 → 保留。
   - App 包内部文件 → 原样保留。
2. **自动过滤 DMG 安装辅助文件**：隐藏布局文件、`.background`、`Applications` 替身。

> 原文见设置页帮助，逐字对应"系统辅助文件包括 __MACOSX、AppleDouble、.DS_Store、Thumbs.db、desktop.ini 和卷索引…"。

## 5. 完成动作

```
解压完成后：
  □ 自动选中解压结果（在 Finder 中显示并选中）
  如何处理压缩包： [每次均询问 | 始终保留 | 始终移入废纸篓]
  □ 自动关闭压缩包（仅在"保留"时可用）
```

规则：

- 只有 **全部解压成功** 才处理原包；部分失败一律保留。
- "始终移入废纸篓"只对直接解压生效；其他完成选项静默保留。
- 移入废纸篓失败 → "解压已完成，但无法将原压缩包移入废纸篓：%@"
- 包仍有进行中操作 / 有未保存修改 → 拒绝移入废纸篓并说明原因。

## 6. 失败语义（部分成功是常态）

| 场景 | 行为 |
|---|---|
| 部分条目密码错误/损坏 | 解出可用内容，统计跳过数："已解压可用内容，跳过 %d 个文件；源压缩包已保留。" |
| 一组文件同一密码 | 按组提示："请输入"%@“等 %d 个文件的密码"；跳过则该组整体不解 |
| 单个文件密码不同 | 单独提示，可"跳过此文件" |
| 全部失败 | "操作失败"，带错误详情（路径/代码/请求编码） |
| 取消 | "操作已取消"，已写文件按事务清理 |

**密码分组**：同一压缩包内可能多个密码。先尝试"上次成功的密码"（"已使用上次成功的密码"），再按密码本候选，最后按"密码相同的成员组"批量询问。密码本对同一密码的多个文件做 group 提示。

## 7. 安全检查（必须在写盘前做）

原版的拒绝清单（全部来自二进制文案）：

- 绝对路径（`/etc/...`）
- 父目录跳转 `..`
- NUL 字节
- 空路径
- 文件/目录结构冲突（`a` 既是文件又是目录）
- 符号链接指向解压根之外（"ZIP 符号链接目标超出提取范围"、"dangerous link path was ignored"）
- 特殊文件（FIFO、设备节点、socket）→ 默认不解压（"特殊文件默认不解压"）
- 超长路径 / 超预算条目（"Member output exceeds budget"、"Member metadata is too large"）
- 硬链接跨边界

实现建议：**先构建"解压计划"**（目标路径 → 条目），做完全部路径规范化与冲突检测，再开始写。原版反复出现"解压请求格式与已验证目录不一致"、"所选条目与压缩包目录不一致"，就是在对比计划与实际。

## 8. 事务与清理

```
staging: <session>/Extract-<uuid>/        （私有、空目录）
   ↓ 写入 + 校验（大小/CRC）
publish: 逐项 rename 到目标目录（同卷）或 copy+fsync（跨卷）
   ↓
cleanup: 删除 staging；登记表标记完成
```

- 中途失败：已发布项**不回滚**（用户可见部分结果），staging 清空，报告"部分完成" `[推断]`。
- 进程被杀：下次启动按 `temporary_artifacts` 清理 staging；已发布项保留。
- 目标在外部卷（exFAT）时，属性写入可能失败但不影响内容；原版修过"exFAT 上因清理辅助文件误报失败"。

## 9. 批量解压

- 选中多个包 → 警示"同时浏览大量压缩包可能占用较多系统资源"，可选 `浏览` 或 `批量解压…`。
- 逐个解压，汇总：`%d extracted, %d errors, %d skipped`。
- 结束后询问是否把**成功解压的**原包移入废纸篓（失败/跳过保留）。
- 同一批共享密码尝试（"此密码也会用于尝试解锁本组中的其他加密压缩包"）。

## 10. 进度与提示

阶段文案：

```
Preparing → Checking Archive → Starting Extraction → Decoding Compressed Stream
→ Extracting → Finishing → Completed
```

进度面板并发显示：`Other active tasks: N`、`Waiting: N`、`Failed: N`。

## 11. 关键设置键

```
extraction.opening.direct                         # 双击快速解压
extraction.completion.reveal_results              # 自动选中结果
extraction.completion.action                      # keep / trash / ask
extraction.automaticallyClosesArchive.v1
extraction.automaticallySelectsResults.v1
extraction.extractsOnExternalOpen.v1
extraction.filtersSystemAuxiliaryFiles.v1
extraction.filtersDMGInstallerArtifacts.v1
```

> `[实证]` 键名与文案；`[推断]` 部分默认值（过滤与自动选中默认开，双击解压默认关）。
