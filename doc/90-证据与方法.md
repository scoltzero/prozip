## 3. 采集方法（可复现）

### 3.1 包结构

```bash
APP=/path/to/ArcZip.app
plutil -p "$APP/Contents/Info.plist"
codesign -d --entitlements :- "$APP"
codesign -d --verbose=4 "$APP"
lipo -archs "$APP/Contents/MacOS/ArcZip"
find "$APP/Contents" -maxdepth 2
```

### 3.2 字符串与偏移

```bash
# 长串（>=4）
strings -a analysis/ArcZip.arm64 > strings_arm64.txt
# 短串（>=2），格式白名单/扩展名需要
strings -n 2 -a analysis/ArcZip.arm64 > strings_n2.txt

# 按偏移取一段 __cstring（例如 SQLite schema）
python3 - <<'PY'
b=open('analysis/ArcZip.arm64','rb').read()
start,end=0xc54e00,0xc57a00
off=start
for p in b[start:end].split(b'\0'):
    if p: print(f'{off:x}\t{p.decode("utf-8","replace")}')
    off+=len(p)+1
PY
```

### 3.3 类型与源码清单

```bash
grep -oE '_Tt[CVAO][A-Za-z0-9_]+' strings_arm64.txt | sort -u > tt-syms.txt
xcrun swift-demangle < tt-syms.txt > types.txt

grep -oE '[A-Za-z0-9_]+/[A-Za-z0-9_]+\.swift' strings_arm64.txt | sort -u
```

得到 248 个 Swift 类型、101 个源码文件名。

### 3.4 运行时结构

```bash
defaults export com.maczhang.ArcZip - > defaults.plist
sqlite3 ~/Library/Caches/com.maczhang.ArcZip/Temporary/Sessions/<pid>-<uuid>/Indexes/index-*.sqlite '.schema'
sqlite3 -readonly <db> "select path, hex(payload) from entries limit 3;"
```

### 3.5 UI

```bash
# 窗口与几何
CGWindowListCopyWindowInfo（见 data 中的采集脚本思路）
screencapture -x -o -l <windowID> shot.png

# AX 树（按 role/title/desc/identifier/position/size）
ax dump <pid>
```

截图：`data/screenshots/`（Mini、Workspace、设置-通用、压缩、Flow、解压）。

## 8. 已知盲区

以下没有做到"逐条动态验证"，开源实现时需自行验证：

1. **具体压缩级别映射**（Balanced 对应 deflate level 几）——字符串里没有。
2. **7zz 的完整 switch 组合**——运行时拼接，静态未见。
3. **密码本加密算法与文件格式**——只确认了 Keychain + 文件密钥的结构。
4. **商业 API 的请求/响应字段**——只确认端点与状态机。
5. **Box 的拖拽会话实现**——AX 无法枚举，只确认了窗口与 4 个动作。
6. **部分阈值常量**（缩略图批次上限、成员读取预算的数值）——只有文案没有数值。
7. **x86_64 slice 的差异**——本次只分析 arm64。

## 9. 复现注意事项

- `strings` 默认丢 1–3 字符的串，格式白名单必须用 `-n 2`。
- SQLite 是 WAL 模式，直接读可能缺最新事务；用 `-readonly` 并接受 `-wal` 未合并。
- AX 在应用弹出原生 sheet 时可能整体返回空；以截图 + `CGWindowList` 为准。
- 截图的窗口 ID 每次启动都会变，别写死。
