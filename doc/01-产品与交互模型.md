# 01 · 产品与交互模型

## 1. 产品定位

ArcZip 是 macOS 上的"压缩包工作台"，不是单纯的解压工具。它把「打开压缩包」拆成三层体验：

1. **看一眼**：Mini 窗口（560×422），双击压缩包即开，列表 + 预览 + 全部解压。
2. **干活**：完整 Workspace，三栏（列表 / 检查器 / 底部操作条），支持搜索、所选解压、编辑保存、分卷、加密。
3. **随手收**：菜单栏 Box（暂存架），把散落各处的文件先收进来，再统一压缩/解压/分享。

外围还有四个系统入口：Finder 右键菜单（Finder Sync）、Quick Look 缩略图、服务菜单（6 项）、`arczip://` URL Scheme。

## 2. 窗口形态

| 形态 | 尺寸 | AX 标识 | 说明 |
|---|---|---|---|
| Workspace | 默认 1040×740，另测 900×700 / 1200×760 | `ArcZip.Workspace.<UUID>` | 完整工作区；顶部工具栏 + 面包屑 + 列表 + 右侧检查器 + 底部 Flow 条 |
| Mini | 560×422 | `ArcZip.Mini.<UUID>` | 轻量浏览；底部一排圆形按钮 + 右下「预览/全部解压」 |
| Box | 521×497（可见卡片约 253×267） | `ArcZip.MenuBarShelf` | 菜单栏弹层，无 NSButton，靠悬停展开 4 个动作 |
| Settings | 900×712 | `ArcZip.SettingsWindow.Immersive` | 左侧 11 个面板，独立窗口 |
| 进度面板 | 附属窗口 | `ArcZip.Progress*` | 多任务队列：进行中 / 等待 / 失败计数 |

> `[实证]` 尺寸来自 `CGWindowList` 实测与 `NSWindow Frame` 持久化键；`[实证]` 标识符来自 AX `AXIdentifier`。

### 2.1 Workspace 布局（1040×740 实测）

```
┌──────────────────────────────────────────────────────────────┬───────────────┐
│ ● ● ●   名称 ⟋        [图标|列表|分栏] [删除] [保存] [搜索]    │  压缩包详情    │
│  ← → ↑  │ sample.zip                                          │  ┌─────────┐  │
│ ┌──────────────────────────────────────────────────────────┐ │  │  缩略图  │  │
│ │ 名称            大小            修改时间                  │ │  └─────────┘  │
│ │ 📁 sub           —              2026-11-09 …              │ │  sample.zip   │
│ │ 📄 blob.bin      200 KB         …                         │ │  ZIP 压缩包    │
│ │ 📄 readme.txt    13 字节        …                         │ │  大小   201 KB │
│ └──────────────────────────────────────────────────────────┘ │  项目   4      │
│ [⤡ 切换到 Mini] [⬆ 全部解压 ⏎] [👁 预览 空格]                   │  加密   否     │
└──────────────────────────────────────────────────────────────┴───────────────┘
```

- 列表列：`名称 / 大小 / 修改时间`（列表视图）。图标视图与分栏视图复用同一数据源。
- 右侧检查器（`Inspector`）：压缩包缩略图、类型、大小、项目数、是否加密、修改日期；选中条目时切换为条目详情。
- 底部 Flow 条左对齐、底部锚定；同一位置在三种窗口宽度下**保持像素一致**（为了命中测试）。
- 空压缩包/新建态：中间出现虚线拖放区「添加文件到压缩包 / 点击添加文件，或直接将文件拖到这里」。

> `[实证]` 截图：`data/screenshots/workspace.png`、`mini.png`、`settings.png`、`compression.png`、`flow.png`、`extraction.png`。

### 2.2 Mini 布局

- 顶部：文件图标 + 文件名 + 「ZIP 压缩包 · 4 个项目」+ 右上 ArcZip 品牌与 `Mini` 胶囊。
- 面包屑一行（返回 / 上一级 / 当前包名）。
- 列表：只有「名称 / 大小」两列。
- 底部：左 `关闭` `置顶` `展开为完整窗口` 三个圆形按钮；右 `预览 空格` 与 `全部解压 ⏎`。
- Mini 的列表是**普通 NSTableView**（`ArcZipApp.MiniFileTableView`），不是 outline；行层级恒 0。

### 2.3 Box（菜单栏暂存架）

- 菜单栏图标常驻；拖文件到图标或弹层即收集；无文件时左下不显示 ⚡。
- 有文件后出现 ⚡，**悬停**展开 4 个动作：放入工作区 / 放入文件夹 / 压缩 / 快速压缩。
- 弹层内是可见卡片（约 253×267），数据只存在内存，磁盘无暂存目录。
- 设置项：启用、颜色（8 色）、色彩浓度、闲置自动收起（秒）、外观预览。

> `[实证]` 窗口 identifier 与"无 NSButton、AX 不返回"来自 AX 探测记录；`[推断]` 4 个动作的行为来自菜单文案与 `ShelfArchiveCreation`/`ShelfFolderBrowser` 类型。

## 5. 免费 vs Pro（原文口径）

免费版明确包含：

> "Free includes opening, browsing, previewing, full extraction, and basic ZIP creation with the General purpose and Balanced compression."
> 中文：「免费版仍可使用打开、浏览、预览、完整解压，以及通用分享 + ZIP + 均衡强度的基础压缩。」

Pro 功能分组（设置页与 onboarding 一致）：

| 分组 | 具体能力 |
|---|---|
| 更多格式与创建预设 | 7Z / TAR 创建；5 种用途；压缩强度滑杆；加密；分卷 |
| 自由修改现有压缩包 | 添加/删除/重命名/替换并保存 |
| 全部 Flow | 打开文件、安装应用、安装字体、安装 pkg、添加文件等动作 |
| 高级压缩与安全 | 加密头、密码本自动保存/自动解锁/预设、ZIP AES（路线图） |
| 包内搜索 | 按名称/路径搜索 |
| 悬浮预览 | 悬停看图片/文档/音视频 |
| 快捷安装 | DMG 内应用"快速安装"（去隔离标记） |

价格（内购页文案）：单用户 **¥68**，三用户 **¥99**；试用 **7 天**，无需注册与支付信息。

## 6. 首次启动 Onboarding（v2，8 步）

`欢迎 → 文件格式关联 → Finder 右键菜单 → 文件访问（完全磁盘访问，可选） → Mini 介绍 → Box 介绍 → Pro 介绍 → 完成（选择默认窗口形态）`

关键行为：

- 格式关联页给"常用格式 / 全部格式"两档，PKG 仍交给系统安装器。
- 文件访问页是**可选**的：普通压缩包不需要完全磁盘访问；开启是为了读微信等来源目录。
- Finder 页要求到系统设置里打开扩展；提供"前往扩展设置"按钮。
- 完成页二选一：`默认用 Mini 打开` / `默认用完整工作区打开`，写入 `archiveOpening.prefersMiniWindow.v1`。
- 记录：`onboarding.hasCompleted.v1`、`onboarding.currentPage.v2`、`onboarding.pendingArchivePaths.v1`。

> `[实证]` 文案与键名；`[推断]` 步骤顺序由 `onboarding.v2.step.*` 与页面 key 推得。

## 7. 主要用户旅程

### A. 双击压缩包 → 看内容 → 解压

```
Finder 双击 → LaunchServices → App 接收 open(urls)
  → 检查偏好：Mini 还是 Workspace
  → 预处理（iCloud/FileProvider 未下载则等待，显示「正在准备打开」）
  → 建会话 + 建索引（preliminary 先出首屏）
  → 列表可浏览；索引完成后解锁搜索/预览/拖出/解压所选
  → 「全部解压」→ 选目标（默认同目录）→ 过滤辅助文件 → 写盘 → 选中结果
  → 按偏好处理原包（询问/保留/废纸篓）
```

### B. 右键 → 快速解压到当前目录

Finder Sync 菜单 `快速解压到当前目录` → XPC/服务调用 → 不建窗口 → 完成后通知（成功/部分/失败）→ 可选把原包移入废纸篓。

### C. 新建压缩包

```
⌘N / 菜单「创建压缩包」/ 拖文件到 Dock 图标 / Box → 压缩
  → 空工作区（虚线拖放区）+ 检查器
  → 添加文件（可多个）→ 选用途/格式/强度/分卷/密码
  → 压缩（临时文件 + manifest 校验）→ 原子发布
  → 保存到目标位置；同名冲突：替换 / 同时保留
```

### D. DMG 装机

```
打开 .dmg → hdiutil 只读挂载 → 渲染卷内布局（背景图、图标坐标、Applications 替身）
  → 双击 .app：校验签名/公证 → 提示"拖到应用程序"或「快速安装」(Pro)
  → 安装：解压/复制/去隔离/写发布记录 → 打开
```

## 8. 交互细节约定

- **选中才出动作**：Flow 条上的「打开文件」只在选中条目时出现；未选中时整条 Flow 隐藏或降级。
- **键盘**：空格 = 预览，回车 = 全部解压，⌘⇧O = 打开选定条目（原版无此键，属扩展入口），⌘, = 设置。
- **多窗口**：每个压缩包可开一个工作区；窗口标题常是「未命名压缩包.zip」，不能靠标题判断内容；同一路径已在别的窗口打开时提示"请在那个窗口中操作"。
- **窗口关闭保护**：有进行中任务时关闭 → "此窗口仍有任务正在进行"；有未保存修改 → "是否保存对 … 的修改？"。
- **退出保护**：有任务时退出 → "任务完成后将自动退出。也可以取消退出"。
- **拖放**：外部文件拖入 = 新增到压缩包/暂存架；内部条目拖出 = file promise（`PromiseDragSource`/`FilePromiseTaskRegistry`），落到 Finder 才真正解包。
- **辅助项目**：`显示辅助项目` 开关控制 `__MACOSX`、`.DS_Store`、`Thumbs.db`、卷索引等是否出现在列表；解压默认过滤。

> 证据索引：AX 树、截图、`Localizable.strings` 键值见 [90-证据与方法](90-证据与方法.md)。
