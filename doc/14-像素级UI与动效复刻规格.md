## 4. 按钮逻辑与动效

- 视图切换：`matchedGeometryEffect` 28pt 圆点滑动，spring(response 0.24, damping 0.82)。
- 工具圆钮：hover 背景提亮 + `scale 1.03`，按下 `scale 0.95`，disabled 透明度 0.35。
- 面包屑导航：hover 背景 `primary.opacity(0.05)`；前进/后退按历史栈启用。
- 行：hover 4% 黑、选中 8% 黑，press 立即高亮；双击目录整表切换（level 恒 0）。
- Flow 主按钮：选中变化时以 `scale(0.9)+opacity` 过渡；hover 亮度 +4%、按下 scale 0.97。
- Mini 圆钮：hover 描边增强；置顶激活为黄绿；彩色窗口按钮开关控制红/橙/绿。
- 文件盒闪电：hover 以 `easeInOut(0.15)` 向上展开 4 个动作。
- 弹窗：sheet 出现 0.22s easeOut，按钮 hover 0.12s。

## 5. 验收方式

1. 同尺寸窗口截图（2×），用像素扫描比对边界/行高/文字基线。
2. AX 树坐标逐项对照（±1pt）。
3. 录屏（`screencapture -v`）对比 hover / press / 切换动效帧。
