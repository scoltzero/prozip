# 08 · 磁盘映像、应用与字体安装

DMG/ISO 不是"当压缩包读"，而是**挂载成卷，再按 Finder 的语义浏览**。ArcZip 把这块做成了独立子系统（`DiskImageEngine` + `DiskImagePresentationLimits` + `ISOReadStrategyStore`）。

## 1. 支持范围

| 类型 | 读 | 写 | 说明 |
|---|---|---|---|
| DMG（含加密） | ✅ 挂载 | ❌ | 加密 DMG 需密码（"ISO 不支持 DMG 密码"是反例说明 DMG 支持） |
| ISO / 光盘镜像 | ✅ 挂载，失败回退解析 | ❌ | 回退引擎只支持浏览+复制，不支持"提取应用" |
| 其他 `hdiutil` 可挂载格式 | ✅ | ❌ | 统一按只读卷处理 |

## 2. 挂载与呈现

```
hdiutil attach -readonly -nobrowse -noautoopen <image>
  → 解析 stdout 进度（HDIUtilProgressLineParser）
  → 得到挂载点 /dev/diskXsY
  → 读卷内布局：
       .background/<img>        背景图
       .DS_Store                图标坐标、窗口尺寸、排列方式
       Applications -> /Applications   （symlink，is_dmg_applications_shortcut）
  → 渲染"磁盘映像视图"
```

视图规则：

- 有 `.DS_Store` 坐标 → 按坐标绝对定位图标，背景图铺底，**还原发布者设计**。
- 没有坐标的项目 → 收进「其他项目」区（"Items without a usable position appear here"）。
- 支持图标视图 / 列表视图切换；图标位置可读不可写（只读挂载）。
- 卷根下的隐藏布局文件默认过滤（`is_disk_image_background`）。

> `[实证]` 文案、类型名、`hdiutil` 路径；`[推断]` `.DS_Store` 解析由 `DSStore-LICENSE.txt` 与背景图资源佐证（内置了 DSStore 解析库）。

## 3. 许可协议（SLA）

DMG 可带 `SLAResources` / 许可文本：

- 挂载后先弹许可（`DiskImageLicenseDialog`）：`同意` / `不同意`。
- 不同意 → 卸载并关闭，不留窗口。
- 原文："此磁盘映像包含需要确认的使用许可协议"。

## 4. 打开卷内应用

双击 `.app`：

1. 校验包结构（`Contents/Info.plist`、`Contents/MacOS/<exe>`、`CFBundleIconFile`）。
2. 校验签名：
   - 无签名 → "没有任何代码签名，无法确认发布者。"
   - 仅 ad-hoc → "仅有临时（ad-hoc）签名，无法确认发布者。"
   - 未公证 → "has not been notarized by Apple."
   - 正常 → "已由 Apple 公证。"
3. 判断安装位置：
   - 卷内有 `Applications` 替身 → 建议拖过去（"开发者建议先将 … 拖到"应用程序"文件夹"）。
   - 开发者指定了自定义目标 → 读 `.DS_Store`/卷结构，提示"开发者为此应用指定了安装位置"。
   - 多个目标 → "开发者为此应用提供了多个安装位置"。
4. 用户可选择：
   - `安装应用`（复制到 /Applications，替换需确认）
   - `交给 macOS 打开此应用`（直接从只读卷启动——不推荐，原版会警告）
   - 取消

## 5. 安装流水线（14 个阶段）

`application.install.stage.*` 原文顺序：

```
prepare-stage              准备临时目录
extract-application        解压应用
validate-application       验证应用包
prepare-destination        准备安装目录
prepare-publication        准备发布记录
read-quarantine            读取来源隔离属性
write-quarantine           写入应用隔离属性
copy-application           复制到安装目录
move-application           移入安装目录
replace-application        替换现有应用
remove-quarantine          移除应用根目录隔离标记
finalize-metadata          完成安装元数据
publish-application        发布新应用
record-installation        记录安装状态
```

关键行为：

- **替换确认**：「`%@` 已经存在于“应用程序”文件夹。继续安装会使用压缩包中的版本替换它。」
- **隔离属性**：默认继承来源 quarantine；"快速安装"（Pro）会去掉根目录隔离标记以减少“未识别开发者”提示——设置页明确写"仅在信任应用来源时开启"。
- **失败详情**：`安装阶段 / 来源 / 目标 / 系统 / 错误详情` 五段式，方便定位。
- 安装完成后可"保留/移入废纸篓"原包 + 自动关闭窗口（与解压同款偏好）。

> `[实证]` 阶段名与文案；`[推断]` quarantine 的具体 xattr 键（`com.apple.quarantine`）为标准实现。

## 6. 拖放导出（从卷里拖出）

- 卷是只读的，拖出 = 复制到目标。
- 目标校验：存在、是目录、可变；开发者指定的目标不可用 → "开发者指定的拖放目标当前不可用"。
- 冲突：询问替换；拖放期间目标变化 → "目标位置出现了新的同名项目，请重新拖动并确认替换"。
- 导出后校验："解压任务未生成 `%@`"。
- `DiskImageInternalDrag` 处理"卷内拖动"（只改图标位置，不复制）与应用内部拖放的区别。

## 7. 字体安装

| 项 | 规则 |
|---|---|
| 触发 | 压缩包/卷内 `.ttf/.otf/.ttc` 双击或 Flow「安装字体」 |
| 目标 | `~/Library/Fonts`（当前用户） |
| 校验 | 必须是字体文件；"所选项目不是字体文件" |
| 冲突 | 已存在同名字体 → 提示："…继续安装会使用压缩包中的字体替换它。" |
| 权限 | 无写权限 → "没有权限写入当前用户的字体库" |
| 完成 | "字体安装完成" + 可选在字体册中查看 |

> `[实证]` 文案；`[推断]` 具体注册 API（CoreText `CTFontManagerRegisterFontsForURL`）。

## 8. ISO 回退路径

挂载失败时走归档解析：

- 能浏览、能复制条目；
- **不支持**"提取应用"（无法保证 bundle 完整性）；
- 错误原文："ISO 无法挂载，且没有可用的归档解析回退引擎"、"ISO 回退引擎缺少所需能力："。

## 9. 错误词典（映像相关）

| 现象 | 文案 |
|---|---|
| 文件没了 | `找不到磁盘映像，请确认文件仍然存在` |
| 没权限 | `没有权限读取此磁盘映像：` |
| 格式不支持 | `macOS 不支持此磁盘映像格式：` |
| 校验失败 | `磁盘映像校验失败` |
| 挂载被干扰 | `macOS 多次尝试后仍无法挂载此磁盘映像，可能受到磁盘工具、安全软件或系统服务干扰` |
| 正在忙 | `macOS 仍在处理此磁盘映像，请稍后重试。` |
| 找不到 app | `磁盘映像中找不到有效的应用程序包` |
| 启动交接失效 | `磁盘映像应用启动交接不存在或已释放` |

## 10. 会话与清理

- 挂载点记录在 `Temporary/DiskImageMounts/`；窗口关闭或应用退出时 `hdiutil detach`。
- 异常退出后下次启动扫描残留挂载点并清理（只清理自己挂的卷）。
- 应用启动交接：`ApplicationLaunchHandoffs/` 存"从只读卷启动 app"的临时上下文，避免 app 因卷卸载而崩溃。
