## 夹具生成

```bash
mkdir -p /tmp/fx && cd /tmp/fx

# 1) 普通包
mkdir -p a/sub && echo hi > a/readme.txt && printf 'x' > a/sub/中文名.txt
(cd a && zip -qr ../plain.zip .)

# 2) 路径穿越包（用 Python 构造，zip 命令会拒绝）
python3 - <<'PY'
import zipfile
z=zipfile.ZipFile('evil.zip','w')
z.writestr('../../evil.txt','pwn')
z.writestr('/tmp/abs.txt','pwn')
z.close()
PY

# 3) 符号链接包
mkdir -p s && ln -s /etc/passwd s/link && (cd s && zip -qry ../symlink.zip .)

# 4) 加密包（ZipCrypto）
zip -q -P secret -r enc.zip a

# 5) 7z 加密（头加密）
7zz a -t7z -psecret -mhe=on enc.7z a >/dev/null

# 6) 大包（1 万个空文件）
python3 - <<'PY'
import zipfile
z=zipfile.ZipFile('many.zip','w',zipfile.ZIP_DEFLATED)
for i in range(10000): z.writestr(f'd{i%50}/f{i}.txt', 'x'*100)
z.close()
PY
```

## 判定口径

- **P0**：不过就不能发版（数据安全/主链路）。
- **P1**：影响体验或格式覆盖，发版前尽量过。
- **P2**：锦上添花。

每次回归至少跑 P0 全量 + 改动相关 P1。
