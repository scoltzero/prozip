## 4. 商业层（行为）

### 4.1 状态机

```
free ──startTrial──> trial(7d) ──expire──> free
  │                    │
  │                    └──activate──> pro
  └──activate──> pro ──deactivate/refund/revoke──> free / invalid
```

状态文案：`Activated / Trial Active / Trial Ended / Not Activated / Local License Invalid / License Refunded / License Deactivated on This Mac`。

### 4.2 授权凭据

- `Info.plist` 内嵌 P-256 公钥（`ArcZipLicenseTrustedKeys`，keyID `production-2026-09-v1`），服务端私钥签发激活载荷。
- 凭据存 Keychain（Data Protection），需要 team `J5W6R92F8U` 的 access group。
- `ArcZipLicenseAPIBaseURL = https://api.arczip.app`，代码里**精确字符串比较**；改成本地地址会 fatal（`invalidAPIBaseURL` / `invalidCommercialDistribution`）。
- 版本覆盖：`ArcZipLicenseCurrentMajorVersion = 1`；授权只覆盖 1.x，跨大版本要求升级。

### 4.3 API 端点（实测路径，方法为推断）

```
/v1/licenses/activate
/v1/licenses/refresh
/v1/licenses/deactivate
/v1/licenses/devices
/v1/licenses/replace
/v1/licenses/replacement-devices
/v1/licenses/trial
```

> 路径来自 `__cstring`；HTTP 方法未在字符串中出现，按语义推断（`devices` 很可能是 GET，其余 POST）。

网络约束：`SecureURLSessionTransport` + `RejectRedirectDelegate`（拒绝重定向，防劫持）；离线时进入"无法连接授权服务"分支，但不影响免费功能。

### 4.4 设备席位

- 每个授权有设备数上限（文案 `%lld of %lld devices activated`）。
- 停用本机 / 远程停用旧设备 / 换机转移（`replace`）。
- 本地移除授权**不释放**服务器席位（"本地授权已移除。服务器设备名额未发生变化。"）。
- 设备名 1–100 字符、无控制字符。

### 4.5 试用

- 7 天，无需注册/支付；服务端记录"已用过"（`trialAlreadyUsed`）。
- 失败原因：网络 / 服务不可用 / 系统时间异常 / 已用过。

> `[实证]` 键、URL、文案、API 路径；`[推断]` 请求/响应字段未提取（不在本次范围）。

## 6. 清理与容量

- 高级页显示"可清理的临时文件"总量，可一键清理；正在使用的文件与用户原文件不动。
- 清理范围：会话目录、预览物化、过期挂载点、登记表中 `state` 为可回收的产物。
- 启动时后台做一次 `TemporaryFilesMaintenance`（孤儿会话、残留临时文件、未完成事务恢复）。

## 7. 崩溃恢复顺序（启动时）

```
1. 打开全局 temporary-artifacts.sqlite（WAL）
2. 扫描 archive_publications：
     prepared/backingUp → 回滚
     committed          → 清临时
     recoveryUncertain  → 保留并提示
3. 扫描 Sessions/：pid 不在运行 → 整个目录删除
4. 扫描 DiskImageMounts/：残留挂载 → detach
5. 扫描临时产物：核对 device/inode/birthtime，不匹配则不动
6. 恢复完成后再允许新建任务
```

> 这是"能放心强杀进程"的关键。开源版若省掉这层，用户迟早会遇到半成品包或误删。
