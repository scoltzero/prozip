## 五、环境限制

1. macOS 27 移除 `hdiutil attach -agree` / `diskutil image attach` 无法接受 SLA，CLI 无法完成带协议 DMG 的自动挂载。
2. D-12 自定义文件访问引导仅在读取其他 App 沙盒/受限目录时出现，本机无可控样本。
3. W-07 更新概览窗口在 ArcZip 1.2.3 实机菜单点击无响应，未取得对照图。

## 六、验收结论（2026-11-10）

- **窗口 / 主界面**：W-01～W-06、W-08、W-09 已完成像素级对照；W-07 因 ArcZip 实机菜单无响应未取得对照图，ProZip 视图已实现。
- **弹窗**：D-01～D-04、D-06、D-08、D-11、D-13 已取得 ArcZip 实机截图并逐项对齐；D-05/D-07/D-10 已实现但受 ArcZip 解锁版完整性校验或缺少触发样本限制，未做逐像素对照；D-09 确认为静默修复；D-12 系统 TCC 弹窗不属于应用 UI。
- **按钮与动效**：工具栏圆钮、视图切换、Flow 主按钮、Flow Orbit 流光、Mini 关闭/置顶、文件盒闪电、创建面板底栏、弹窗按钮均已实现，关键项有像素差分或快照证据。
- **功能**：真实打开/索引/解压/预览/创建/编辑保存/工具菜单压缩解压/SLA 检测已接线；格式关联仅持久化 UI 状态，未调用 LaunchServices。
- **构建**：`swift test` 30 项全过；`bash scripts/build_app.sh debug` 产出 `build/ProZip.app`。
- **环境边界**：macOS 27 移除 `hdiutil -agree`，带 SLA 的 DMG 只能交由系统 DiskImageMounter 挂载；ArcZip 解锁版的完整性校验会禁用密码本面板。

后续可直接在 `Sources/ProZipUI/*` 与 `Sources/ProZipShared/ProZipTheme.swift` 上改品牌、布局与文案；对照坐标见 `doc/14` / `doc/15`，证据在 `doc/evidence/`。
