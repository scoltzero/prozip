# 06 · 密码与密码本

## 1. 密码请求链路

```
条目/包加密
  → ArchivePasswordCoordinator 计算"需要密码的范围"
  → 先试"上次成功的密码"（同包/同组）
  → 再试密码本候选（Pro 自动解锁；免费手动）
  → 仍失败 → 弹密码框（带包名/条目名、可显示密码、可勾选"保存到密码本"）
  → 校验：quick check（读一小段验证）→ 通过则记录；失败提示"密码错误"，不写入
```

要点：

- **密码只在内存**：默认"密码只保存在当前窗口的内存中"。
- **验证分级**：`ArchivePasswordQuickCheck` 只验证头部/首个条目，避免为了试密码解整包。
- **多密码包**：`encryptionGroupID` 把同一密码的条目分组；`password_book.archive.multiple` 说明"此压缩包包含多个密码，读取时会自动匹配"。
- **不把密码写进 argv**：7zz 用占位符 + 安全管道（`writePassword(_:to:)`、`-p__ARCZIP_NO_PASSWORD__`）。

> `[实证]` 类型名与文案；`[推断]` 校验顺序。

## 2. 密码输入体验

| 特性 | 说明 | 键 |
|---|---|---|
| 默认显示密码 | 方便中文/日文输入法与候选；仍可用眼睛按钮临时隐藏 | `archivePassword.revealsByDefault.v1` |
| 输入法提示 | 首次弹"输入非英文密码"提示：先点眼睛显示再输入，或直接粘贴 | `archivePassword.inputNoticeSuppressed.v1` |

| 记住选择 | "不再提示" | 同上 |
| 错误提示 | `Incorrect Password / 密码错误`，可重试 | — |

## 3. 密码本（Password Book）

### 3.1 能力

| 功能 | 免费 | Pro |
|---|---|---|
| 手动输入密码打开/解压 | ✅ | ✅ |
| 自动保存密码 | ❌（可手动"保存"？） | ✅ |
| 自动用密码本解锁 | ❌ | ✅ |
| 密码预设（创建时快速选） | ❌ | ✅ |
| 密码本主密码保护 | 记录保留但受限 | ✅ |
| Touch ID / Apple Watch 快速解锁 | — | ✅ |

原文："自动保存、自动解锁、密码预设和密码保护均属于 ArcZip Pro。已有记录会保留；手动输入密码打开和解压仍可免费使用。"

### 3.2 数据模型

```
PasswordBook
├── entries: [PasswordBookEntry]     // 名称、密码、备注、创建/使用时间
├── fileKey: PasswordBookFileKey     // 加密文件内容的密钥
├── keychain: PasswordBookKeychain   // 主密钥存 Keychain（Data Protection）
└── storage: PasswordBookStorage     // 加密文件（可导出/备份）
```

- 密码本内容**加密落盘**，密钥存 Keychain（`SystemPasswordBookKeychain`）。
- 主密码派生密钥解锁文件密钥；Touch ID 解锁的是 Keychain 里的同一把钥匙。
- 记录与压缩包**不是硬绑定**：一条密码可服务多个包；修改记录不会改已有包的密码（"修改此记录不会更改已有压缩包的密码"）。
- 支持"密码预设"：创建加密包时从下拉选。

### 3.3 保护与重置

- 设置主密码：两次输入一致；可"开启保护/关闭保护"。
- 忘记主密码且无法快捷解锁 → **只能重置并清空密码本**（"请牢记此密码；忘记密码且无法使用快捷解锁时，只能重置并清空密码本"）。
- 密码本锁定状态：`Password Book is locked / 正在载入密码本…`。

> `[实证]` 文案、类型名、键名；`[推断]` 加密算法（很可能是 AES-GCM + Keychain），实现可自选，但**必须**满足：文件密钥随机、主密码只用于包裹、Keychain 存包裹钥匙。

## 4. 加密创建侧

| 项 | ZIP | 7Z |
|---|---|---|
| 密码字符集 | ASCII | 任意 Unicode |
| 加密算法 | ZipCrypto（传统） | AES-256 |
| 加密文件名 | 否 | 是（`encryptHeaders`） |
| 分卷 + 加密 | 支持（7zz 路径） | 支持 |
| 密码本保存 | 支持 | 支持 |

创建时校验：

- 开保护但空密码 → "请设置密码，或关闭密码保护"
- 两次不一致 → "两次输入的密码不一致"
- ZIP 非 ASCII → 阻止并提示改用 7Z

## 5. 与提示/错误的关系

| 场景 | 文案 |
|---|---|
| 打开加密包 | "此压缩包受密码保护" / "Browse the file list freely. Click the lock to enter a password…" |
| 头部加密 | 未输入密码前列表不可见（"没有密码时不显示压缩包内容"） |
| 错误密码 | "Incorrect Password"；7zz 原文 `Cannot open encrypted archive. Wrong password?` |
| 密码组跳过 | "这些文件需要同一个密码。跳过会保留整组文件未解压" |
| 批量共享 | "此密码也会用于尝试解锁本组中的其他加密压缩包" |

## 6. 安全红线（原版明确不做的事）

1. 不把密码放进命令行参数。
2. 不在日志里打印密码。
3. 不把密码写入普通 UserDefaults（只有"是否显示/是否提示"这类布尔）。
4. 不为了"支持 ZIP AES 写入"而降级到不安全实现——宁可先不支持。

> 这四条直接决定开源版的密码模块设计：**安全通道 + Keychain + 内存生命周期**，缺一不可。
