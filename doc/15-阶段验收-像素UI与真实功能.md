## 23. 拖动闪烁修复（改用 AppKit performDrag）

- 现象：拖动时窗口不断闪烁、不跟手。
- 原因：SwiftUI `DragGesture` 每次 `onChanged` 都 `setFrameOrigin`，窗口移动会改变手势坐标空间，形成「移动→坐标变化→再移动」的反馈环；同时 `mouseDownCanMoveWindow=true` 可能让 AppKit 与 SwiftUI 同时移动窗口。
- 修复：
  - 移除 SwiftUI 拖动 modifier 与 `DraggableHostingView` 的双重移动；
  - 新增 `WindowDragArea`（NSView 子类）在 `mouseDown` 调用 `window.performDrag(with:)`，交给 AppKit 原生平滑拖动；
  - 只在顶部空白区域放置拖拽条：欢迎页 x=80..510/y=0..44；工作区 x=80..180 与 200..460/y=0..52；Mini x=80..440/y=0..50；设置侧栏品牌区 210×100。
- 实测：欢迎页拖动 `(872,233)→(972,283)`、工作区 `(632,145)→(712,195)`，位移与鼠标一致，无闪烁；按钮区域不在拖拽条内，点击不受影响。
